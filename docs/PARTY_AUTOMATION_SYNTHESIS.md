# 동행 편성·스킬 자동사용·특수개체 합성 보완

## 동행 편성 UI
- 왼쪽에 전체 보유 동료를 이미지·별·레벨·출전/대기/보관 상태의 3열 카드 표로 표시한다. 한 번에 9마리를 보고 나머지는 스크롤한다.
- 오른쪽에 전투 출전4와 교체 대기2를 분리한다. 왼쪽 동료를 선택한 후 오른쪽 칸으로 배치한다. 이미 편성한 동료면 두 자리 교체, 보관 동료면 대상 교체다.
- 슬롯만 눌러 현재 동료를 선택할 수도 있다. 선택 후 같은 칸을 누르면 선택 해제한다.
- 기존 compact 순서 배열을 보존하므로 빈칸은 앞쪽 출전부터 채운다. 동행 해제 시 뒤 동료가 앞당겨지며 상태 표기도 즉시 갱신한다.
- 캠프에서는 전체 보유 동료를 추가·교체·해제한다. 탐험 비전투 중에는 기존 동행끼리 교체하며 HP·쿨다운을 보존한다. 전투/튜토리얼 중 편성은 차단한다.
- 종·1~6성·즐겨찾기 필터와 정렬, 상세·비교·육성·작별·합성 기능을 유지한다. 필터/정렬/선택은 편성이나 동료 메타데이터를 바꾸지 않는다. 선택·즐겨찾기 조작 시 목록 스크롤을 보존한다.
- 편성·즐겨찾기는 저장 성공 후 메모리에 반영하며 실패하면 기존 파일과 파티/잠금을 유지한다. 선택/스크롤은 저장 필드가 아니다.
- 실제 검증과 화면: `docs/ROSTER_LAYOUT.md`.

## 동료 스킬 자동사용
- HUD에 `자동 스킬 ON/OFF` 버튼을 추가하고 root v2 저장의 선택 필드로 보존한다. 구세이브와 잘못된 값은 OFF다.
- 수동 초상 버튼과 1~4 단축키는 그대로 사용할 수 있다.
- 공격형은 유효한 전투 대상이 있을 때 사용한다.
- 사슴은 범위 안 아군 체력이 70% 미만일 때 사용한다.
- 거북은 주변 적이 2마리 이상이거나 보스가 가까울 때 사용한다.
- 쓰러짐·재사용 대기·진행 중인 스킬·소생 중에는 자동 사용하지 않는다.

## 4성 특수개체 합성 후보
- 조건: 서로 다른 3성 Lv.40 세 마리, 주재료 한 마리 지정, 성공 100%, 추가 재화 없음.
- 종 보존: 주재료와 같은 종 100%.
- 포지션 보존 후보:
  - 전열: 멧돼지 / 거북, 각 50%.
  - 공격: 담비 / 늑대 / 동굴박쥐, 각 약 33.3%.
  - 원거리·지원: 여우 / 사슴, 각 50%.
- 별도 신규 특수종은 이름·수치·그림·확률이 미승인이므로 후보에 추가하지 않는다.
- 주재료 ID·특성·즐겨찾기·편성·기존 옵션을 유지한다. 보조 두 마리는 소모한다.
- 동행 중 보조 재료는 후보로 선택할 수 있으며 최종 확인에 표시한다. 저장 성공과 같은 트랜잭션에서 동행 해제·소모한다.
- 즐겨찾기 보조 재료는 계속 차단한다. 결과는 4성 Lv.1, 신규 랜덤 옵션 2개이며 이후 속성과 고유 능력을 선택한다.

## 검증 경계
- 저장 실패 시 자동사용 설정, 동행 편성, 합성 재료와 RNG가 변경되지 않아야 한다.
- 자동사용은 고정 조건 검사이며 사람 플레이의 최적 타이밍을 보장하지 않는다.
- 입장 재화는 이번 범위에서 추가하지 않는다.
