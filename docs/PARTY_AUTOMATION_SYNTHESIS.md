# 동행 편성·스킬 자동사용·특수개체 합성 보완

## 동행 편성 UI
- 동료 관리 상단에 실제 동행 6칸을 항상 표시한다.
- 1~4번은 전투 출전, 5~6번은 대기 동료다.
- 비전투 중 두 슬롯을 차례로 누르면 출전과 대기 위치를 직접 교체한다.
- 캠프에서는 아래 전체 보유 목록에서 동행 추가·해제를 계속 할 수 있다. 필터와 정렬은 편성 순서를 바꾸지 않는다.

## 동료 스킬 자동사용
- HUD에 `자동 스킬 ON/OFF` 버튼을 추가하고 root v2 저장의 선택 필드로 보존한다. 구세이브와 잘못된 값은 OFF다.
- 수동 초상 버튼과 1~4 단축키는 그대로 사용할 수 있다.
- 공격형은 유효한 전투 대상이 있을 때 사용한다.
- 사슴은 범위 안 아군 체력이 70% 미만일 때 사용한다.
- 거북은 주변 적이 2마리 이상이거나 보스가 가까울 때 사용한다.
- 쓰러짐·재사용 대기·진행 중인 스킬·소생 중에는 자동 사용하지 않는다.

## 4성 특수개체 합성 후보
- 조건: 서로 다른 3성 Lv.40 세 마리, 주재료 한 마리 지정, 성공 100%, 추가 재화 없음.
- 종 보존: 주재료와 같은 종 100%.
- 포지션 보존 후보:
  - 전열: 멧돼지 / 거북, 각 50%.
  - 공격: 담비 / 늑대 / 동굴박쥐, 각 약 33.3%.
  - 원거리·지원: 여우 / 사슴, 각 50%.
- 별도 신규 특수종은 이름·수치·그림·확률이 미승인이므로 후보에 추가하지 않는다.
- 주재료 ID·특성·즐겨찾기·편성·기존 옵션을 유지한다. 보조 두 마리는 소모한다.
- 동행 중 보조 재료는 후보로 선택할 수 있으며 최종 확인에 표시한다. 저장 성공과 같은 트랜잭션에서 동행 해제·소모한다.
- 즐겨찾기 보조 재료는 계속 차단한다. 결과는 4성 Lv.1, 신규 랜덤 옵션 2개이며 이후 속성과 고유 능력을 선택한다.

## 검증 경계
- 저장 실패 시 자동사용 설정, 동행 편성, 합성 재료와 RNG가 변경되지 않아야 한다.
- 자동사용은 고정 조건 검사이며 사람 플레이의 최적 타이밍을 보장하지 않는다.
- 입장 재화는 이번 범위에서 추가하지 않는다.
