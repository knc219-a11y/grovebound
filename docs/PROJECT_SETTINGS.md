# Grovebound · 공통 설정과 개발 방향

이 문서는 같은 프로젝트의 새 대화에서 공유할 확정 설정이다. 최신 구현/검증 상태는 STATUS.md와 NEXT_SESSION.md를 함께 확인한다. 사용자 지시로 바뀐 결정은 이 문서도 갱신한다.

## 프로젝트 식별
- 현재 프로젝트: 몬스터 수집형 RPG Grovebound, 저장소 https://github.com/knc219-a11y/grovebound . 과거 Godot ARPG/다른 저장소의 세계관을 자동으로 합치지 않는다.
- Godot4.7 Standard, 모바일 가로화면. 기본 자동 전투에 이동·지원·동료 특수 스킬로 개입한다.
- 현재 주인공은 드루이드 하나. 활동 동료4마리/준비6마리, 같은 종 중복 편성 가능. 새 주인공 캐릭터/직업 생성은 아직 하지 않는다.

## 공통 운영 확정 (2026-10-21)
- 기존 총괄·분야별 개발·독립 QA에 게임 기획 사전/사후 검토를 추가한다. 상세 절차는 `docs/MULTI_AGENT_DEVELOPMENT.md`, 기획 책임/조사/판정은 `docs/agents/GAME_DESIGNER.md`, 새 Work 시작문은 `docs/WORK_PROMPT.md`가 단일 기준이다.
- 기획은 제안과 검토를 맡고 확정 설정·밸런스·범위를 독자 변경하지 않는다. 최종 결정/배분은 총괄, 중요한 미정 설정·기획·밸런스 변경은 사용자와 합의한다. 실행 환경별 하위 역할 지원을 확인하며 문서만으로 자동 실행을 보장하지 않는다. 게임 콘텐츠·수치·저장 정책은 이번 운영 변경으로 바뀌지 않는다.

## 세계관·캠페인 확정 (2026-10-20)
- 야수·마물·영혼이 이루던 자연의 순환이 다섯 지역에서 끊겨 흉포화와 영혼의 정체가 발생한다. 드루이드는 경계를 푼 야수와 인연을 맺고 동료들과 순환을 복원한다. 마물/언데드 전체를 악으로 규정하지 않으며 미래 계열별 인연과 연결한다.
- 최종 적은 세계를 지키려 순환을 멈췄지만 그 대가로 세계를 병들게 한 수호자다. 일반에서는 지역 연결을 복구하고, 심층에서는 오염의 뿌리, 도전에서는 되살아나는 잔재를 제압한다. 구체 인명/대사/과거 사건은 미정이다.
- 일반→심층(가칭)→도전(가칭). 난이도마다 5테마×8스테이지=40개, 전체120개 진행 단위. 테마별 4번은 중간보스, 8번은 테마 보스. 일반5-8로 심층, 심층5-8로 도전을 해금한다.
- 기존 계곡/채석장/묘역을 첫3테마로 확장한다. 신규4·5테마는 사용자 선택으로 황야→성채를 진행한다. 가칭은 붉은바람 황야/검은성채,신규적은 가시마물·주술사·파수꾼과 혼합수호대·최종수호자다. 신규 적 전투수치/보상은 실제검증하며 조정한다. 작은 소품·열린 전투공간·작은 캐릭터·넓은 시야·승인 그림풍·활동4/준비6 보존.
- 지도는 세계의 테마 선택→테마 내부 스테이지 노드 선택. 클리어한 스테이지 재방문 가능. 기존3지역 완료/해금은 명시적 호환 정책을 설계하고 보존한다.
- 디아블로2의 난이도별 재진행 구조를 참고하되 고유 세계관을 사용한다. 상위 난이도는 적 조합/정예/패턴/보상으로 차별화한다. 적 속성저항/면역은 자동 도입하지 않는다.
- 기존5성 수치/5·6성 승인능력/동료ID·종·특성·옵션·편성·사용자 저장 보존. 앞서 제시한 황야 난이도별XP1500/3500/6500과 교감성급확률은 승인되지 않았다.
- 설계 상세와 미정/구현 순서는 docs/WORLD_CAMPAIGN_DESIGN.md. 지도/일반 계곡8개 구현은 docs/CAMPAIGN_MAP.md,채석장8개 확장은 docs/QUARRY_ROUTES.md,묘역8개와첫승급경제는 docs/GRAVEYARD_ROUTES.md. 현재 일반40개는 구현 완료했고 심층/도전80개는 미구현이다. 일반5-8의심층해금/지도상태는저장하며 미구현출발은차단한다. 상세 docs/FRONTIER_ROUTES.md.
- 현재 새 스테이지의 첫 클리어는 보상 적당 동행6 각각12+적레벨×4XP/일반재료1/보스5/클리어10/야수교감15%·1성/약한추가무리무보상 수식을 유지한다. 8개 독립탐험으로 나누므로 테마전체 보상합은 옛 단일지역과 다르다. 새 완료는 본선전체제압 후 해당테마출구표식F/화면길잇기로 확정하며 보너스/진행은 저장성공후동시반영한다.
- 저장version2에 campaign_progress.version1의 난이도/테마/스테이지 좌표를 추가했다. 기존완료지역은 원본백업후 해당일반테마8개완료로 이관하고 채석장/묘역 기존탐험을 보존한다. 미구현노드는 출발불가이며 기존동료/옵션/편성/진화조건은 보존한다.

## 수집과 앞으로의 직업
- 드루이드는 야수와 교감해 인연을 맺는다. 사용자 문구는 교감·인연·동료 쉼터·자연으로 보내기. 내부 저장 키 captures는 호환을 위해 보존한다.
- 적은 야수(beast), 마물(monster), 언데드(undead) 계열로 구분한다. 향후 다른 직업도 자기 계열을 테이밍할 수 있게 종의 계열/교감 조건을 전투 AI·스테이지 배치와 분리한다.
- 드루이드=야수 계열은 확정. ‘계약술사/사령술사’ 등의 다른 직업명과 상세 능력은 가칭·후속 설계다. 데이터 정책용 식별자를 준비해도 해당 주인공이 구현됐다고 설명하지 않는다.
- 어떤 직업이 테이밍할 수 있는지와 어떤 동료를 편성할 수 있는지는 별개 결정이다. 미래 직업의 편성 제한을 임의로 확정하지 않는다.
- 현재 직업이 교감할 수 없는 마물/언데드는 전투와 생물 도감의 대상으로 등장할 수 있다. 누를 수 없는 교감 기회를 무작위로 남기지 않는다.

## 전투와 스테이지
- 일반5테마×8개와 세계/테마 지도는 구현됐다. 채석장/묘역의 기존 탐험도 유지한다. 심층/도전 실제 스테이지는 준비 중이다. 현재 작업은 일반 검토 수정과 아래 첫4성/재탐험 성장 목표가 우선한다.
- 다수의 약한 적을 동료 스킬로 시원하게 제압하는 전투를 지향한다. 소규모 교전→다수전→휴식→보스의 리듬을 섞고, 모든 무리의 숫자를 계속 올리지 않는다.
- 일반 무리는 몰아잡기, 정예/지원 적은 우선순위 판단, 보스는 읽을 수 있는 공격 예고와 회피/지원 타이밍을 담당한다.
- 현재 멧돼지 관통 돌진과 여우 범위 폭발이 다수전 기준이다. 다른 동료의 신규 다수전 능력은 하나씩 검토한다.
- 기존 단일지역의 A안 혼합 배치(기존 탐험 경로에 적용): 초록물 계곡은 야수, 버려진 채석장은 마물, 잊힌 묘역은 언데드 중심이며 세 지역 모두 세 계열이 등장한다. 일반 보상 대상11은 주력7/다른 계열 각2, 보스와 추가 약한 무리는 주력 계열. 총28/30/30과 보상 대상12를 유지한다. 소수 계열도 일반 보상 대상이어야 한다.
- 기존 단일 계곡은 첫 동료 멧돼지/담비/여우 한 마리와 추가 교감0회를 기준으로 조정한다. 계곡에 생성되는 일반 적의 피해는 종 기본값의80%, 추가 약한 적은 기존 무리 피해의50%로 완화한다. 보스/다른 지역/동료 기본 능력치와 성장 공식은 유지한다. 자동 검증과 사람 난이도 판단은 구분한다.
- 첫 동료는 확정 획득 튜토리얼→협동 연습→마을 준비. 현재 드루이드3종 선택을 유지한다. 미래 마물 첫 종은 슬라임, 언데드 첫 종은 해골병으로 정책 데이터만 준비한다. 해당 직업/동료 AI/직업 전환·입문 저장은 아직 구현하지 않는다.
- 재료/XP/교감 확률·등급·성장 수치는 무리 숫자 증가에 맞춰 무단 증폭하지 않는다. 현재 추가 약한 적은 제압 수만 늘리고 별도 성장/교감 보상을 주지 않는 실험 정책이다. 사용자 피드백으로 재검토할 수 있다.

- 일반 채석장8개는 슬라임 무리/바위 강타/박쥐 교감/해골병 혼합과2-4중간·2-8테마보스로 연결한다. 1-8→2-1/테마내순차해금/2-8→기존묘역 출발을 보존한다. 일반적Lv4~7/보스5·8과900·1600HP는 새 구간의 현재 구현값이며 기존채석장1050HP나동료5·6성능력을바꾼값이아니다. 정확한보상표/검증범위는QUARRY_ROUTES를따른다.

## 아트와 비율
- 승인된 선명한 쿼터뷰 도트풍과 절제된 팔레트. 논리1440×810, 월드2900×1650. 드루이드 전체72px/몸체60px, 일반 멧돼지48px가 기준이다.
- 작은 캐릭터와 넓은 시야를 유지한다. 큰 배경 소품 문제를 캐릭터 확대나 카메라 줌으로 해결하지 않는다. 새 지역도 사람 크기에 맞는 작은 소품과 충분한 전투 공간을 만든다.
- 독립 지팡이와 무기 외형 교체 API, 승인 원화/기존 맵을 보존한다. 생성 시안과 실제 Godot 실행 화면을 구분한다.

## 성장·저장·검증
- 개체값(IV) 없음. 종·레벨 기본 능력치 + 고정 특성1개 + 등급별 무작위 옵션. 기존 개체 재추첨 금지. 기회 생성 시 확정한 메타데이터를 획득/화면 열기/저장 로드에서 보존한다.
- 기존 세이브/진행도/다른 로컬 변경 보존. 자동 조작·녹화는 사용자 저장과 격리한다.
- 실제 Godot 검증·회귀 검사·GIF/MP4를 제공하고 GitHub ref 확인 후 반영 완료라고 말한다. 봇의 고정 시드 한 번 결과를 사람의 성공률/난이도 검증으로 바꾸어 설명하지 않는다.
- iPhone/Windows 등 확인하지 않은 실기기를 검증 완료라고 표시하지 않는다.
- 동료 관리는 왼쪽 이미지·별·레벨·편성 상태의 3열 보유 목록과 오른쪽 출전4+대기2 고정 슬롯으로 구성한다. 목록에서 선택 후 오른쪽 슬롯을 눌러 배치·교체한다. 비전투 중 출전·대기 슬롯을 직접 교체할 수 있다. 동행은 기존 순서 배열을 보존하며 빈자리는 앞쪽 출전 칸부터 채운다. 동료 스킬 자동사용은 수동 버튼을 대체하지 않는 선택형 ON/OFF이며 저장한다.
- 3성 Lv.40 세 마리 특수개체 합성에서 동행 중 보조 재료는 최종 확인 후 합성 트랜잭션과 함께 동행 해제·소모한다. 주재료 편성은 유지하고 즐겨찾기 보조는 계속 보호한다.

## 성장 개편: 합성·승급·특수개체 (단계별 구현 중)
- 상세와 다음 Work 시작 문장: `docs/SYNTHESIS_HANDOFF.md`. 저장v2·성급 상한·1→2→3성 실제 승급은 구현됐다. 3→4 실제 소비·고정 결과 저장·선택 복구·4성 성장/능력까지 구현됐다. 4→5 진화는 구현됐고 5→6 실행도 구현됐다. 일반/희귀/영웅은 호환용 내부 식별자다.
- 1~3성은 일반 동료로 사냥에서 획득. 최대 레벨은 1성20/2성30/3성40/4성50/5성60. 6성까지 성장시키며 6성 최대 레벨은70이다.
- 현재 구현된 초반 스테이지에서는 야생 1성만 획득한다. 아직 구현하지 않은 후속 스테이지는 스테이지별 정책으로 2·3성까지 허용한다. 후속 스테이지의 정확한 성급 확률은 미정이다.
- 1성Lv20→같은 동료2성Lv1, 2성Lv30→같은 동료3성Lv1로 별도 재료 없이 승급한다. ID·종·특성·잠금·기존 옵션·편성은 유지하며1~3성 외형은 바꾸지 않는다.
- 승급 직후 원시 체력·공격력은Lv1에 맞게 감소한다. 대신 레벨당 체력/공격 성장률은1성12%/10%,2성17%/14%,3성26%/22%로 커져2성은 약Lv15,3성은 약Lv20에 이전 성급 만렙 전투력을 다시 넘는다.
- 3성Lv40 동료3마리를 합성해 랜덤4성 특수개체를 소환한다. 매 합성에서 주재료를 지정하고 종 보존/포지션 보존을 선택한다. 포지션은 전열(멧돼지·거북), 공격(담비·늑대·박쥐), 원거리·지원(여우·사슴)이다.
- 4성 결과는 기존7종 특수개체를 기본 풀로 사용하고, 낮은 확률로 별도 신규 특수종도 나올 수 있게 별도 목록을 둔다. 신규 특수종의 이름·수치·그림과 정확한 등장 확률은 후속 확정 전까지 비워 두며 임의로 생성하지 않는다.
