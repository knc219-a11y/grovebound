# Grovebound · 공통 설정과 개발 방향

이 문서는 같은 프로젝트의 새 대화에서 공유할 확정 설정이다. 최신 구현/검증 상태는 STATUS.md와 NEXT_SESSION.md를 함께 확인한다. 사용자 지시로 바뀐 결정은 이 문서도 갱신한다.

## 프로젝트 식별
- 현재 프로젝트: 몬스터 수집형 RPG Grovebound, 저장소 https://github.com/knc219-a11y/grovebound . 과거 Godot ARPG/다른 저장소의 세계관을 자동으로 합치지 않는다.
- Godot4.7 Standard, 모바일 가로화면. 기본 자동 전투에 이동·지원·동료 특수 스킬로 개입한다.
- 현재 주인공은 드루이드 하나. 활동 동료4마리/준비6마리, 같은 종 중복 편성 가능. 새 주인공 캐릭터/직업 생성은 아직 하지 않는다.

## 수집과 앞으로의 직업
- 드루이드는 야수와 교감해 인연을 맺는다. 사용자 문구는 교감·인연·동료 쉼터·자연으로 보내기. 내부 저장 키 captures는 호환을 위해 보존한다.
- 적은 야수(beast), 마물(monster), 언데드(undead) 계열로 구분한다. 향후 다른 직업도 자기 계열을 테이밍할 수 있게 종의 계열/교감 조건을 전투 AI·스테이지 배치와 분리한다.
- 드루이드=야수 계열은 확정. ‘계약술사/사령술사’ 등의 다른 직업명과 상세 능력은 가칭·후속 설계다. 데이터 정책용 식별자를 준비해도 해당 주인공이 구현됐다고 설명하지 않는다.
- 어떤 직업이 테이밍할 수 있는지와 어떤 동료를 편성할 수 있는지는 별개 결정이다. 미래 직업의 편성 제한을 임의로 확정하지 않는다.
- 현재 직업이 교감할 수 없는 마물/언데드는 전투와 생물 도감의 대상으로 등장할 수 있다. 누를 수 없는 교감 기회를 무작위로 남기지 않는다.

## 전투와 스테이지
- 다수의 약한 적을 동료 스킬로 시원하게 제압하는 전투를 지향한다. 소규모 교전→다수전→휴식→보스의 리듬을 섞고, 모든 무리의 숫자를 계속 올리지 않는다.
- 일반 무리는 몰아잡기, 정예/지원 적은 우선순위 판단, 보스는 읽을 수 있는 공격 예고와 회피/지원 타이밍을 담당한다.
- 현재 멧돼지 관통 돌진과 여우 범위 폭발이 다수전 기준이다. 다른 동료의 신규 다수전 능력은 하나씩 검토한다.
- A안 혼합 배치: 초록물 계곡은 야수, 버려진 채석장은 마물, 잊힌 묘역은 언데드 중심이며 세 지역 모두 세 계열이 등장한다. 일반 보상 대상11은 주력7/다른 계열 각2, 보스와 추가 약한 무리는 주력 계열. 총28/30/30과 보상 대상12를 유지한다. 소수 계열도 일반 보상 대상이어야 한다.
- 계곡은 첫 동료 멧돼지/담비/여우 한 마리와 추가 교감0회를 기준으로 조정한다. 계곡에 생성되는 일반 적의 피해는 종 기본값의80%, 추가 약한 적은 기존 무리 피해의50%로 완화한다. 보스/다른 지역/동료 기본 능력치와 성장 공식은 유지한다. 자동 검증과 사람 난이도 판단은 구분한다.
- 첫 동료는 확정 획득 튜토리얼→협동 연습→마을 준비. 현재 드루이드3종 선택을 유지한다. 미래 마물 첫 종은 슬라임, 언데드 첫 종은 해골병으로 정책 데이터만 준비한다. 해당 직업/동료 AI/직업 전환·입문 저장은 아직 구현하지 않는다.
- 재료/XP/교감 확률·등급·성장 수치는 무리 숫자 증가에 맞춰 무단 증폭하지 않는다. 현재 추가 약한 적은 제압 수만 늘리고 별도 성장/교감 보상을 주지 않는 실험 정책이다. 사용자 피드백으로 재검토할 수 있다.

## 아트와 비율
- 승인된 선명한 쿼터뷰 도트풍과 절제된 팔레트. 논리1440×810, 월드2900×1650. 드루이드 전체72px/몸체60px, 일반 멧돼지48px가 기준이다.
- 작은 캐릭터와 넓은 시야를 유지한다. 큰 배경 소품 문제를 캐릭터 확대나 카메라 줌으로 해결하지 않는다. 새 지역도 사람 크기에 맞는 작은 소품과 충분한 전투 공간을 만든다.
- 독립 지팡이와 무기 외형 교체 API, 승인 원화/기존 맵을 보존한다. 생성 시안과 실제 Godot 실행 화면을 구분한다.

## 성장·저장·검증
- 개체값(IV) 없음. 종·레벨 기본 능력치 + 고정 특성1개 + 등급별 무작위 옵션. 기존 개체 재추첨 금지. 기회 생성 시 확정한 메타데이터를 획득/화면 열기/저장 로드에서 보존한다.
- 기존 세이브/진행도/다른 로컬 변경 보존. 자동 조작·녹화는 사용자 저장과 격리한다.
- 실제 Godot 검증·회귀 검사·GIF/MP4를 제공하고 GitHub ref 확인 후 반영 완료라고 말한다. 봇의 고정 시드 한 번 결과를 사람의 성공률/난이도 검증으로 바꾸어 설명하지 않는다.
- iPhone/Windows 등 확인하지 않은 실기기를 검증 완료라고 표시하지 않는다.

## 성장 개편: 합성·승급·특수개체 (단계별 구현 중)
- 상세와 다음 Work 시작 문장: `docs/SYNTHESIS_HANDOFF.md`. 저장v2·성급 상한·1→2→3성 실제 승급은 구현됐다. 3→4 실제 소비·고정 결과 저장·선택 복구·4성 성장/능력까지 구현됐다. 4→5/5→6진화는 미구현이다. 일반/희귀/영웅은 호환용 내부 식별자다.
- 1~3성은 일반 동료로 사냥에서 획득. 최대 레벨은 1성20/2성30/3성40/4성50/5성60. 6성까지 성장시키는 방향이며 6성 최대 레벨은 미정이다.
- 현재 구현된 초반 스테이지에서는 야생 1성만 획득한다. 아직 구현하지 않은 후속 스테이지는 스테이지별 정책으로 2·3성까지 허용한다. 후속 스테이지의 정확한 성급 확률은 미정이다.
- 1성Lv20→같은 동료2성Lv1, 2성Lv30→같은 동료3성Lv1로 별도 재료 없이 승급한다. ID·종·특성·잠금·기존 옵션·편성은 유지하며1~3성 외형은 바꾸지 않는다.
- 승급 직후 원시 체력·공격력은Lv1에 맞게 감소한다. 대신 레벨당 체력/공격 성장률은1성12%/10%,2성17%/14%,3성26%/22%로 커져2성은 약Lv15,3성은 약Lv20에 이전 성급 만렙 전투력을 다시 넘는다.
- 3성Lv40 동료3마리를 합성해 랜덤4성 특수개체를 소환한다. 매 합성에서 주재료를 지정하고 종 보존/포지션 보존을 선택한다. 포지션은 전열(멧돼지·거북), 공격(담비·늑대·박쥐), 원거리·지원(여우·사슴)이다.
- 4성 결과는 기존7종 특수개체를 기본 풀로 사용하고, 낮은 확률로 별도 신규 특수종도 나올 수 있게 별도 목록을 둔다. 신규 특수종의 이름·수치·그림과 정확한 등장 확률은 후속 확정 전까지 비워 두며 임의로 생성하지 않는다.
- 4성부터 속성 등 고유 능력과 랜덤 부가옵션이 생긴다. 소환 후 속성이나 고유 옵션을 선택하며 이미 정해진 랜덤 옵션은 유지한다. 속성/고유 능력 각각의 선택 범위·개수·수치는 아래4성 특수개체 규칙을 따른다.
- 4성부터는 외형 표식·오라 등으로 특수개체임이 분명해야 하며, 특수 스킬·속성·고유 옵션 때문에Lv1부터 단순 원시 능력치 이상의 효율을 갖게 한다. 현재4성은 아래 규칙의 효과와 작은 표식/오라로 구현한다.
- 4성Lv50 주 동료+4성Lv50 재료 동료→주 동료5성 진화(특수 옵션 추가). 같은 방식으로 5성Lv60 주 동료+5성Lv60 재료 동료→주 동료6성 진화. 주 동료를 성장시키는 구조이며 재료 동료 전체 옵션을 무조건 계승하는 규칙은 없다.
- 기존 일반/희귀/영웅은 각각1/2/3성으로 이관한다. ID·종·레벨·XP·특성·잠금·기존 옵션을 보존하고, 상한 초과 기존 동료는 강제로 낮추지 않되 추가 XP를 막는다. 기존 옵션은 이관 옵션으로 계속 적용하고 신규1~3성은 고정 특성만 가지며 랜덤 부가옵션은 붙이지 않는다.
- 4→5/5→6성의 레벨 초기화 여부, 승급 직후 능력치, 성공률/비용, 재료 종·계열 제한은 미정이다. 기존 동료/옵션을 임의 초기화하거나 재추첨하지 않는다. 이 문서의 현재 코드 정책과 미래 목표 규칙을 섞지 않는다.


## 3→4성 합성 추가 확정 (2026-10-20)
- 성공률100%, 추가 비용 없음. 서로 다른 ID의 정확히3성Lv40 동료3마리를 사용한다. 보조 재료는 종 제한이 없으며 준비 편성(동행6)/즐겨찾기이면 소비할 수 없다. 주재료는 동행/즐겨찾기 상태여도 지정 가능하다.
- 결과는4성Lv1. 주재료ID·고정 특성·즐겨찾기·편성·기존 옵션은 종이 바뀌어도 유지하고 보조2마리를 소비한다. 종에 맞지 않아 효과가 없는 기존 옵션도 제거/재추첨하지 않는다. 실제 결과 저장 구현 때 기존 종 적합성 필터를 우회하는 명시적 계승 정책이 필요하다.
- 종 보존은 주재료와 같은 기존 종, 포지션 보존은 같은 포지션의 기존 종 중 균등 추첨한다. 신규 특수종은 정확한 목록/확률 승인 전까지 비워 둔다. 현재 후보 확률은 기존 종만을 대상으로 한 조건부 확률이며 미래 신규 풀의 확률을 확정하지 않는다.
- 후보 미리보기는 동료·재료·RNG를 변경하지 않는다. 이후 사용자 승인으로 실제 소비·소환·결과 저장과 아래4성 규칙까지 구현 범위가 확장됐다.
- 4성 성장/특수스킬/선택·랜덤옵션 규칙은 아래 추가 확정을 따른다. 물은 스킬 재사용 대기시간15% 감소로 확정됐다. 4→5/5→6 비용·성공률·재료 제한과 레벨 초기화,6성 상한도 미정이다.


## 4성 특수개체 규칙 확정 (2026-10-20)
- 4성은 기존 종의 역할을 강화한 특수개체. 기본 체력/공격은 결과 종의3성Lv40 기본값×(0.70+0.022×(레벨−1)). Lv1은70%,Lv15는100.8%,Lv50은177.8%. 특성·계승/신규 옵션·선택 능력은 별도 반영한다. 1~3성 성장률은 유지한다.
- 공통 속성은 불꽃·물·대지·바람. 미래 야수/마물/언데드가 공유하고 계열 개성은 계열 고유 능력과 종별 스킬로 분리한다. 전용 속성/야성·혼돈·망령은 가칭·후속 제안이며 확정/구현하지 않는다. 적의 속성 상성·저항은 이번에 만들지 않는다.
- 불꽃: 공격종 피해+10%,사슴 회복+15%,거북 자신의 방어+1초. 대지:최대체력+12%/받는피해5%감소. 바람:이동속도+8%/스킬대기10%감소. 물: 스킬 재사용 대기시간15% 감소(기본10초→8.5초). 사용자가15%를 선택해 확정했으며 네 속성 모두 선택할 수 있다.
- 소환 후 공통 속성1개 + 현재 결과 포지션의 야수 고유 능력1개를 선택해 영구 확정한다. 미래 마물/언데드는 별도 고유 능력 목록으로 확장하며 현재 직업/동료AI를 추가하지 않는다.
- 전열 고유3택1:최대체력15%/받는피해8%감소/스킬 사용 시 자신에게최대체력10% 보호막4초. 공격 고유3택1:기본공격피해15%/스킬피해15%/체력50%이하 적에게주는피해15%. 원거리·지원 고유3택1:여우 범위피해·사슴회복15%/스킬대기12%감소/여우 폭발·사슴스킬회복반경20%.
- 신규 랜덤 옵션2개는 기존 옵션 종류/수치 범위의 결과 종·고정 특성 적합 풀에서 중복 없이 소환 순간 확정한다. 기존 계승 옵션은 별도로 모두 보존하며 신규와 같은 항목이면 합산한다. 종에 맞지 않는 계승 옵션은 삭제/재추첨 없이 보존하고 현재 종에 미적용임을 표시한다. 선택창 열기/로드/선택 확정으로 랜덤 옵션을 다시 뽑지 않는다.
