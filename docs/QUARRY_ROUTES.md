# 일반 채석장 2-1~2-8

2026-10-20. main c431a57a320284ec0b977bf64722d80255dbb221(PR#3)에서 시작. 이번 범위는 두 번째 테마8개와 계곡→채석장→기존 묘역 연결이다. 현재 새 스테이지는 일반 계곡/채석장16개이며 묘역8분할·신규4/5테마·상위 난이도는 미구현이다.

## 플레이와 이야기

일반1-8 완료→지도에서 채석장2-1 선택→2-8까지 순차 진행. 결과의 다음 스테이지로 이어갈 수 있으며 이전 구간은 재방문한다. 2-4는 균열 바위마물,2-8은 채석장의 돌지기다. 앞 길목 제압+공터 접근 후 보스 진입,전체 본선 제압 후 **채굴로 표식/F·길 잇기**로 완료한다. 옆길 박쥐/해골병은 선택이며 보스 완료 필수가 아니다.

계곡의 돌조각→채석장 운반로→물길에서 옮겨진 돌→반복되는 채굴 명령→붙잡힌 수로→돌지기의 문양과 묘역의 연결로 이야기를 이어간다. 긴 컷신이나 새로운 주인공은 추가하지 않는다. 현재 승인된 수호자/자연 순환 세계관을 바꾸지 않는다.

## 전투·지도·저장

- quarry_routes.gd에8개 데이터와 작은 길목/쉼터/출구/옆길을 정의한다. 승인된 채석장 배경과 슬라임/바위마물/박쥐/해골병의 기존 그림·동작을 사용한다. 새 배경8장 또는 새 종ID를 만든 작업은 아니다.
- 일반 적 Lv4~7/최종보스8. 채석장 일반 적 피해는 기존 지역처럼 전역 기본 배율1,추가 무리는 기존 합산피해 분배/체력28%를 사용한다. 계곡의 일반80%/추가무리50%는 그대로다. 전역 종 능력치를 바꾸지 않는다.
- 중간보스는 자기 주변 강타만 사용하고 최종 돌지기는 자기 주변150px 강타/고정 표적100px 공격을 교대한다. 예고와 실제 판정은 같은 반경이다. 보스 처치만으로 앞 길목을 건너뛰거나 자동 완료하지 않는다.
- campaign_routes.gd를 테마별 데이터와 보스레벨을 읽도록 확장했다. 이전 테마8완료→다음 테마1,같은 테마의 앞 스테이지 완료→다음 스테이지 규칙을 사용한다. 미구현3~5테마/심층/도전의 새 노드는 계속 출발 차단한다.
- valley_trail.gd의 기존 경로 객체는 테마 번호/쉼터/옆길/출구 문구를 데이터에서 읽는다. 화면/카메라/72px 주인공/일반 표시 크기는 유지한다.
- 2-8 완료는 legacy cleared_stages에도2를 기록한다. 결과에서 **잊힌 묘역으로**를 누르면 기존 묘역 탐험으로 이어진다. 새3-1 구현으로 표시하지 않는다. 보너스+진행은 기존 원자적 저장 후 메모리 반영,실패 시 재시도/중복제출 차단을 유지한다.
- 저장v2/campaign_progress.version1 형식은 그대로다. 기존 계곡8분할 진행과 옛 채석장 완료16좌표,동료ID/종/레벨/성급/특성/옵션/즐겨찾기/준비편성을 보존한다. 새 저장 이관이나 초기화는 없다.
- 채석장의 **기존 사냥터 탐험**도 남겨 전환기 기존 진행/재방문 경로를 보존한다. 이 경로의30마리/1050HP 돌지기와 보상은 변경하지 않았다. 옛 전체지역 완료를 새8개 완료로 연결하는 기존 호환 정책을 유지한다.
