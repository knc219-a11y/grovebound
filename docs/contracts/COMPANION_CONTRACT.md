# 동료 계약

- 동료의 안정 식별자는 기존 ID이며 종, 계열, 레벨, 성급, XP, 고정 특성, 옵션, 잠금, 편성, 특수개체 메타데이터를 보존한다.
- 개체값은 추가하지 않는다. 포획 기회에서 정해진 메타데이터는 획득·화면 열기·저장 로드에서 재추첨하지 않는다.
- 드루이드는 야수와 교감한다. 미래 직업명과 마물·언데드 편성 정책은 미정 상태로 둔다.
- 활동 4마리·준비 6마리와 같은 종 중복 편성을 유지한다.
- 성장·합성·진화는 승인된 성급별 상한과 능력을 따르며 기존 옵션을 임의 교체하지 않는다.
- UI는 표시용 복사본을 받아 명령을 요청하고 동료 원본 데이터를 직접 수정하지 않는다.
- 특수개체 합성의 주재료는 편성 자리를 유지한다. 동행 중인 보조 재료는 최종 확인에 표시하고 합성 저장과 같은 트랜잭션에서 동행 해제·소모한다. 즐겨찾기 보조 재료는 계속 차단한다.
