# UI 계약

- UI는 표시 모델을 읽고 도메인 명령을 요청한다. 저장·전투·동료 원본을 직접 변경하지 않는다.
- 명령 결과는 성공, 실패 이유와 갱신된 표시 모델을 구분한다.
- 활동 4·준비 6, 일반 40 진행, 승급 대기와 재탐험 보상 안내를 보존한다.
- 모바일 가로 화면, 터치 안전영역, 작은 캐릭터와 넓은 시야를 유지한다.
- UI 변경은 격리된 검토 장면과 실제 인게임 스크린샷으로 확인한다.
- 미구현 기능은 활성 버튼처럼 표시하지 않으며 차단 이유를 명확히 보여준다.

- 동료 관리는 왼쪽 이미지·별 목록과 오른쪽 출전4/대기2로 표시한다. 선택 후 목적 슬롯으로 배치하며 기존 순서 배열의 빈칸은 앞쪽부터 채운다. 필터·선택·스크롤은 표시 상태이며 동료/편성을 변경하지 않는다.

- 왼쪽 같은 동료·오른쪽 같은 슬롯/ID를450ms 이내 두 번 누르면 캠프에서 동행전환/해제한다. 서로 다른 선택은 편성을 바꾸지 않으며 배치/필터 변경 뒤 클릭상태를 해제한다. 육성 진입 시 편성용 선택해제·스크롤/필터보존. 진화재료와확인에 ID/특성/속성/옵션을 끝까지 읽을 수 있게 표시한다.
