# 전투 계약

- 전투 규칙은 참가자 상태와 명령을 입력으로 받고 피해·회복·상태 효과·처치·교감 기회를 결과로 반환한다.
- UI 효과, 음향과 애니메이션은 규칙 결과를 소비하며 전투 수치를 별도로 계산하지 않는다.
- 시작된 보스 예고·돌진과 거북 도발의 현행 고정 규칙을 보존한다.
- 약한 추가 무리의 무보상, 일반 지역 보상과 최종보스의 승인된 현재 수치를 임의 변경하지 않는다.
- 자동 봇의 고정 시드 결과는 사람 성공률이나 난이도 판정이 아니다.
- 새 상태 효과는 중첩, 갱신, 만료, 사망·장면 전환 정리와 저장 여부를 명시한다.

- 바람은 이동속도+8%와 기본 공격속도+10%(공격간격÷1.10), 속성 스킬 대기 감소 없음. 기존 물/고유/진화 능력 대기 감소는 유지한다.
- 진형은 주인공 마지막 이동방향 기준 앞·뒤·둘러싸기 집결 위치다. 전투 중 종별 대상/사거리/귀환/도발과 시작된 예고는 유지하고 위치를 고정하지 않는다. 실제 공격범위·적 피해/빈도는 변경하지 않는다.
