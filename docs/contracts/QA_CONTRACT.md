# QA 계약

- 기능 작성자와 QA 담당을 분리한다. QA는 재현·판정·증거를 담당하고 제품 수정은 소유자에게 돌려보낸다.
- 모든 실행 결과에서 종료 코드뿐 아니라 PASS 문구, Parse Error와 SCRIPT ERROR를 확인한다.
- 검토·녹화는 사용자 저장과 격리하고 원본 백업 원칙을 지킨다.
- UI·배경은 실제 인게임 스크린샷, 모션은 실제 Godot GIF와 MP4를 제공한다.
- 자동 검사, 준비 팀 QA, 전체 연속 플레이, 사람 플레이와 실기기 결과를 구분한다.
- 결과에는 기준 SHA, Godot 버전, 명령, 시드/준비 상태, 통과 수, 경고와 미검증을 기록한다.
- 통합 PR은 최신 전체 회귀, 저장 왕복·실패 무변경, 캠페인 진행과 동료 보존을 확인한다.
