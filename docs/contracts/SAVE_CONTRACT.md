# 저장 계약

- 기존 `grovebound_v1.json`, 현재 저장 버전과 모든 기존 동료·진행 필드를 보존한다.
- 새 필드는 버전, 기본값, 구세이브 변환, 숫자형 정규화와 왕복 검사를 함께 정의한다.
- ID·종·특성·옵션·잠금·편성·특수개체 선택을 재생성하거나 재추첨하지 않는다.
- 저장은 임시 파일 기록·flush·close 후 교체하는 기존 원자성 원칙을 유지한다.
- 실패하면 메모리, 파일, 소비 재화와 RNG 상태가 모두 변경 전이어야 한다.
- UI와 검토 장면은 저장 파일을 직접 변경하지 않는다. 저장 변경은 통합 리드 소유다.
- 스키마 변경 PR에는 이전/이후 예시, 마이그레이션 테스트와 롤백 계획이 필요하다.
- `auto_companion_skills`는 root v2의 선택 필드이며 누락·비불리언 값은 OFF로 읽는다. 기존 저장 버전은 올리지 않는다.
