# 공통 계약

이 폴더는 병렬 작업 사이의 안정된 경계를 정의한다. 계약 변경은 소비 기능보다 먼저 별도 PR로 병합한다.

- `SAVE_CONTRACT.md`: 저장·마이그레이션·원자성
- `COMPANION_CONTRACT.md`: 동료 정체성과 성장 데이터
- `COMBAT_CONTRACT.md`: 전투 명령과 결과 경계
- `CAMPAIGN_CONTRACT.md`: 진행·출발·완료·보상
- `UI_CONTRACT.md`: 표시 모델과 사용자 명령
- `QA_CONTRACT.md`: 검사와 증거 기준

계약 PR에는 호환성, 영향을 받는 생산자/소비자, 테스트, 롤백과 인계 문서 갱신 여부를 기록한다. 이 문서들은 현재 소스를 대체하는 새 구현 명세가 아니라, 기존 동작을 보존하며 모듈을 분리하기 위한 경계다.
