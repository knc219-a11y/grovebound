# 드루이드 성장 · 골드 · 장비 · 지원 스킬

2026-10-21. 사용자 승인: 지원 드루이드와 동료 중심 전투를 유지하면서 골드, 자동 레벨 성장/능력치창, 장비, 지원 스킬 성장을 추가한다. 동료 승급/합성에 새 골드 비용을 붙이지 않는다. 입장 재화와 심층은 후속 작업이다.

## 이용 방법

메뉴 → 주인공/장비/지원 스킬/장비 상점, 또는 C로 능력치창을 연다. 탐험 중 조회하면 일시정지되고, 구매·판매·장착·해제·강화·스킬 성장은 캠프에서만 가능하다. 변경 확인창에서 골드 전후와 능력치 변화를 확인한다. 장비는 왼쪽 보유 목록을 스크롤해 선택한다. 상점 목록도 스크롤한다.

Q 회복, E 야성 강화, F 길게 소생은 기존 조작이다. Lv.8부터 캠프에서 숲의 보호를 75 G에 배우면 R/화면 버튼으로 주변 아군을 보호한다. 골드/레벨은 상단과 주인공 화면, 탐험 획득 골드/장비 수는 결과창에 표시한다.

## 초기 수치

수치는 첫 구현의 조정 가능한 시작값이다. Lv.1 체력180/공격6/회복55/야성60%/소생3초·체력30%를 보존한다. 최대 Lv.30, 레벨별 필요 XP=현재 레벨×100, 초과 XP 이월, 만렙 XP0. 레벨당 체력8/공격0.3/방어0.2/회복지원1% 자동 증가한다. 수동 능력치 배분은 없다.

주인공 방어력의 피해 배율은 100/(100+방어력). 회복지원은 드루이드 회복량에만 적용한다. 장비의 재사용 감소는 최대30%, Q/E/R에 적용하며 동료의 고유 재사용 시간은 유지한다.

일반 적 골드=5+적 레벨×2, 보스는 그5배, 완료 보너스=30+테마×20. 주인공 XP=12+적 레벨×4. 동료의 후반 재탐험 XP×12/재료×3과 별개이며 주인공 보상에는 해당 배수를 쓰지 않는다. 튜토리얼과 추가 약한 무리는 주인공 XP/골드/장비 무보상이다. 기존 동료·재료 보상은 유지한다. legacy 지역 완료에도 골드 보너스를 준다.

## 장비

무기1/방어구1/부적2칸. 동일 부적 종류의 별도 개체를 함께 착용할 수 있지만 한 장비 ID를 두 칸에 중복 장착할 수 없다. 아이템 고정 능력치와 강화값만 사용하고 무작위 옵션은 추가하지 않았다. 장착 중 판매 불가, 필요 레벨 검사, 해제·교체 지원. 비교는 해당 칸 교체 시 전체 능력치의 차이다.

| 장비 | 필요 레벨 | 가격 G | 기본 효과 |
|---|---:|---:|---|
| 새싹/참나무/숲지기 지팡이 | 1/8/18 | 120/450/1200 | 공격2/4/6, 회복지원3/8/14% |
| 직조/나무껍질/수호자 로브 | 1/8/18 | 100/400/1100 | 체력25/50/80, 방어3/6/10 |
| 생명의 부적 | 1 | 160 | 체력20 |
| 시냇물 부적 | 8 | 500 | 재사용 감소4%, 회복지원3% |
| 바람 부적 | 18 | 1000 | 재사용 감소7%, 방어3 |

보스 장비1개 확정, 일반 적8%. 적 레벨 이하 필요 레벨의 목록에서 결정한다. 드롭은 저장되는 별도 RNG를 쓰며 동료 교감/옵션 RNG를 소비하지 않는다. 결과는 획득 시 확정하고 조회/로드/저장 재시도에 재추첨하지 않는다. 장비 외형은 기존 승인 지팡이/드루이드 그림을 사용하며 종류별 외형 변경은 아직 없다.

강화는 확정 +5까지, 각 단계 기본 효과 +15%씩 합산. 다음 강화 비용=기본 가격/2×(현재 강화+1). 판매는 기본 가격의25%, 강화 비용 환급 없음.

## 지원 스킬

회복/야성/소생은1단계 시작, 보호는 미습득. 최대5단계, 다음 단계 비용=75×다음 단계. 다음 단계 필요 레벨은 회복·야성·소생 1+4×현재 단계, 보호8+4×현재 단계다. 보호 첫 습득은 Lv.8, 최종5단계는 Lv.24다.

| 스킬 | 단계당 증가 | 기본값 |
|---|---|---|
| 회복 Q | 회복+5, 재사용−0.25초 | 회복55, 재사용8초, 반경430 |
| 야성 E | 공격 강화+3%p, 지속+0.5초, 재사용−0.5초 | +60%, 지속7초, 재사용14초, 반경430 공격력 최대 아군1명 |
| 소생 F | 집중−0.2초, 부활 체력+2.5%p | 집중3초, 체력30% |
| 숲의 보호 R | 보호막+2%p | 최대체력8%, 반경350, 지속4초, 재사용18초 |

보호막은 기존 특수 동료 보호막과 강한 양/긴 지속으로 갱신하고 합산하지 않는다. 야성은 대상의 현재 효과값을 사용하며 동료의 승인 기본/5·6성 효과를 변경하지 않는다.

## 저장과 호환

기존 root version2에 독립 hero version1 추가. 기존 저장은 원본 백업 후 Lv.1/골드0/빈 장비/기본 스킬로 이행하며 과거 사냥의 보상은 소급 지급하지 않는다. 동료 ID/종/특성/옵션/즐겨찾기/편성/진행/성장 재료를 보존한다. 미래 hero 버전, 손상된 장비 중복 ID·장착 정보 등은 자동 저장을 중지하고 원본을 보존한다.

캠프 변경은 전체 예상 스냅샷과 현재 상태를 비교하고 후보 저장 성공 후에만 반영한다. 실패/중복 클릭/오래된 확인창에서는 골드/아이템을 소모하지 않는다. 전투 보상은 실패 시 후보를 메모리에 유지해 다음 저장 때 같은 결과를 다시 시도한다. 저장이 계속 불가능한 상태로 종료하면 메모리의 미저장 보상을 복구할 수는 없다.

## 최종 보스와 검증

최대 성장 주인공을 더한 초기 검사에서 전원3성 편성이148.7초에 최종 보스를 제압했다. 사용자의 ‘최소4성 하나’ 조건을 유지하기 위해 순환 갑주를 해제 전 **피해 차단**으로 보완했다. 교전 중 보스600px 이내의 선택 완료4성 이상 동료 강화 스킬로6초 해제하며, 거북/사슴 포함7종 모두 가능하다. 입장 성급 제한은 없고 보스 HUD에 필요 행동을 표시한다. 기존70% 감소안은 이전 구현 이력이다.

Godot4.7.2 Standard에서 새 저장·마이그레이션·원자적 거래·UI 구매 확인·장비·실제 스킬/보호막/재시도 검사50개 통과. 전체 회귀46/46 통과, 결과는 hero-progression-tests.json. 1-1→5-6 첫 인연3종×2시드228/228, 모두 주인공Lv.15/9249 G/장비23개까지 자연 획득. 같은 멧돼지 경로에서4-1 재탐험16회로3성40 세 마리→4성15, 실제 골드로 참나무 지팡이/나무껍질 로브/부적2개와 지원 스킬 성장 후5-7/5-8 완료(최종66.9초). 주인공Lv.17/잔여7755 G. 드롭은 판매하지 않고 보존한 경로다.
