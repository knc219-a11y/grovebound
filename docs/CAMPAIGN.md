# 계곡 → 채석장 → 묘역

2026-10-20. 현재 주인공은 드루이드 하나이며 다른 주인공 생성 기능은 추가하지 않았다. 최신 A안 배치·검증·난이도 조정은 [MIXED_STAGES.md](MIXED_STAGES.md)를 따른다.

## 실제 구현

| 지역 | 해금 | 적과 보스 | 드루이드 교감 |
| --- | --- | --- | --- |
| 초록물 계곡 | 기존 튜토리얼 이후 | 야수 중심, 슬라임·해골병 포함, 총28 | 기존6종 |
| 버려진 채석장 | 계곡 우두머리 제압 | 마물 중심, 박쥐·해골병 포함, 총30 | 본선/선택길 동굴박쥐 |
| 잊힌 묘역 | 채석장 우두머리 제압 | 언데드 중심, 늑대·박쥐·슬라임 포함, 총30 | 선택길 늑대·본선 박쥐 |

마을 동쪽 출발 지점/여정 메뉴의 ‘사냥길 선택’에서 고른다. 권장 동료 레벨1/3/5는 안내이며 입장 제한이 아니다. 클리어 결과에서 다음 지역으로 직접 이어갈 수 있고 마을에서 이전 지역 재방문도 가능하다. 앞 지역 보스 클리어만 필요하며 모든 무리·옆길·쉼터를 강제하지 않는다.

각 새 지역은 본선5/2/8/10과 보스1, 선택2+2로30마리다. 기존 방식의 보상 대상12와 제압 수만 주는 약한 추가18로 나눈다. 일반 보상/성장 공식/15% 교감/보스 클리어+10 정책은 기존 함수를 사용한다. 마물/언데드에게 드루이드의 교감 기회를 생성하지 않으며 야수인 박쥐는 기존 확정 시점/등급/특성/옵션 규칙으로 교감한다.

슬라임/해골은 근접 무리, 바위 마물/수호병은 느린 원형 강타, 망령은 현재 위치에 남긴 원거리 지면 예고를 사용한다. 새 지역 보스는 자기 주변 강타와 고정한 표적 지면 공격을 번갈아 쓴다. 계곡 일반 적 피해80%/추가 약한 무리 피해50%를 적용하며 보스와 다른 지역 수치는 보존한다.

## 확장 경계

`creature_species.gd`는 종 계열/표시 이름과 교감 정책, `campaign.gd`는 지역/해금/배치, `enemy_patterns.gd`는 새 적의 판정, `animation/creature_visual.gd`는4자세 아트를 담당한다. 적의 전투 능력치를 기존 동료 목록에 모두 넣지 않아 마물/언데드가 드루이드 편성에 섞이지 않는다.

`CLASS_FAMILIES`의 druid/beast, contractor/monster, necromancer/undead는 정책 조회를 위한 준비다. contractor/necromancer는 새 주인공 구현이나 확정 직업명, 직업 선택 UI가 아니다. 미래 직업을 실제 추가할 때 해당 종의 동료 AI/성장 능력치·직업별 사용 규칙을 함께 연결해야 한다. 현재 박쥐만 새 드루이드 동료로 편성/육성/기본 공격/급강하 스킬/교감 연출/도감/저장까지 연결했다. 미래 직업의 편성 제한은 아직 확정하지 않는다.

생물 도감은12종을 스크롤로 보여주고 실제 조우 기록/기존 획득 기록을 보존한다. 야수 카드의 기존 ‘동료 찾아보기’ 연결을 유지하며 다른 계열에는 필요한 인연을 안내한다.

## 저장 호환

기존 version1에 cleared_stages/seen_species를 더한다. 옛 unlocked=true는 계곡 제압1개로만 옮기며 채석장/묘역을 무료 해금하지 않는다. 순차 해금과 JSON 숫자 형식을 정규화한다. 기존 동료의 ID/레벨/경험치/즐겨찾기/등급/특성/옵션은 그대로 유지한다. 원정 종료 중복 호출은 보상/해금을 다시 지급하지 않는다. 초기화 버튼은 새 진행 필드도 지운다.

## 모든 대화의 설정 인계

AGENTS.md는 새 결정이 생길 때마다 PROJECT_SETTINGS → STATUS → NEXT_SESSION을 갱신하도록 요구한다. `python tools/check_handoff.py`는 문서 연결과 스테이징된 구현의 인계 동반 여부를 확인한다. GitHub CI는 push/PR의 이전 커밋을 기준으로 같은 누락을 검사한다. 이는 대화 수집 기능이나 ChatGPT 프로젝트 지침을 원격 변경하는 기능이 아니다. 새 대화가 저장소의 AGENTS를 읽는 방식으로 지속한다. CI 실행 결과와 로컬 검사 결과는 구분해서 보고한다.
