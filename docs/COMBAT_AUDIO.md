# 전투 음향 1차

2026-10-19. 외부 게임 음원/녹음 없이 `animation/combat_audio.gd`가 결정적 PCM을 생성한다. 시작 시 19종을 캐시하고 타격마다 합성하지 않는다. 원본 게임의 작고 차분한 도트 화면에 맞춘 짧은 효과음 초안이며 실제 취향/아이폰 스피커 평가는 남아 있다.

- 일반 공격: 멧돼지 낮은 충격, 늑대 거친 베기, 담비 짧고 높은 베기, 여우 맑은 마력 접촉, 거북 둔한 접촉, 사슴 가벼운 접촉. 피격/방어/보스 지면 충격도 구분한다.
- 스킬: 여섯 동료와 드루이드 회복/강화/완료된 소생에 긴 발동음을 연결한다. 실제 성공한 기존 피드백 이벤트를 사용하고 실패한 쿨다운 입력은 무음이다. 공격 준비 때 미리 소리를 내지 않으며 실제 피해 이벤트에서 재생한다.
- 소리는 최대6개, 종류별 일반65ms/스킬120ms 재입력 제한. 포화 시 스킬은 일반음을 대체하며 일반음은 버린다. 스킬 발동 시 재생 중 일반음을 -29dB로 낮추고180ms 동안 새 일반음도 낮춘다. 기본 일반 -24dB/스킬 -18dB. 같은 공격의 추가 impact 시각 이벤트는 무음이다. heal/guard/buff 보조 이벤트도 무음으로 스킬과 중복하지 않는다.
- 세이브/성장/피해/회복/쿨다운/카메라 변경 없음. 음소거 API `set_enabled(false)`는 정지까지 지원하지만 사용자용 설정 화면/저장은 이번 범위에 포함하지 않는다. 기존 교감 등급 알림음은 보존한다.

검증: `tools/test_combat_audio.gd` PCM 결정성/종류별 구분/음성6개/재입력/스킬 우선/음소거/피드백 연결. 기존 `test_attack_timing.gd`, `test_skill_visual.gd`로 판정/스킬 수치 회귀 확인. Godot 실제 전투는 사용자 저장 격리 `animation/skill_v3_review.tscn`의 두 조합/실제 콜백을 사용한다.

`tools/preview.py --audio`는 Godot movie의 소리를 AAC로 보존한다. 기존 기본 무음 출력은 유지. `docs/combat-audio-gameplay.mp4`는 소리 포함, GIF는 무음 미리보기다. 녹음 파형의 무음 여부/피크를 확인하며 청감 최종 승인은 별도다.

다음: 사용자 볼륨/질감 피드백 후 조정, 이후 우두머리 전용 예고/발구르기/돌진/회수 동작, 첫 사냥터 완주 검토 순서. 새로운 스킬/경제/보상은 추가하지 않는다.
