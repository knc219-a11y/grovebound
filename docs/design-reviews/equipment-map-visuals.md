## 추천안과 승인 경계

장비를 얻었음을 알아차리고, 종류를 보고, 보유품과 비교한 뒤 다음 탐험으로 이어지는 흐름을 우선한다. 재미 증가는 가설이며 실제 사람 플레이로 확인한다.

1. 기존 9종 각각에 일관된 도트풍 아이콘을 부여한다. 지팡이·로브·부적의 실루엣과 재질 차이를 우선하고, 희귀도를 암시하는 임의 등급명·색 테두리는 만들지 않는다. 요구 레벨은 성급/희귀도와 구별한다.
2. 보유 목록과 상세 비교를 분리한다. 장착 4칸은 명시적으로 남기고 보유 목록 높이를 확보한다. 종류 필터, 최신 획득/강화 등 명시 정렬과 선택 강조는 표시 상태로만 다룬다. 중복도 ID별로 보존한다.
3. 선택 장비의 필요 레벨·강화·능력치와 현재 장착품 대비 실제 합계 차이를 표시한다. 부적 두 칸을 각각 비교한다. 유효하지 않은 장착은 계획의 실제 실패 이유로 안내하며 모두를 단일 '추천/전투력' 숫자로 압축하지 않는다.
4. 저장 성공으로 공개된 실제 획득품에 한해 아이콘과 이름을 보여 준다. 전투를 막는 신규 획득 팝업은 피하고 기존 알림 또는 결과 화면을 활용한다. 해당 탐험 획득품을 보여 준다면 이전 소지품과 분리하고 재시도 중복 표시를 차단한다. 세이브에 신규 수집 도감/NEW 플래그를 추가하지 않는다.
5. 지도는 세계의 다섯 지역과 각 테마의 지형 실루엣·작은 랜드마크를 달리한다. 계곡의 물길, 채석장의 절삭암·운반 흔적, 묘역의 묘표·문, 황야의 갈라진 지형, 성채의 성벽으로 구분하되 지도 장식은 실제 전투 지형·새 경로를 약속하지 않는다. 경로와 버튼/글자 주변은 조용하게 둔다.
6. 완료·선택·미해금·준비 중과 중간/최종보스 표시는 색 외에 문구/문양으로도 남긴다. 해금·추천·XP/재료/교감·재탐험 안내와 기존 사냥터 진입을 보존한다.

이번 사용자 요청은 위 시각·표시·탐색 개선의 근거다. 새 희귀도, 랜덤 옵션, 새 장비, 드롭률/보장/풀이 변경되는 보상, 판매 환급/강화비 변경, 자동 장착·자동/일괄 판매, 새 저장 필드는 별도 중요 기획이며 이번 범위에서 보류한다. 보상 체계의 장기 재미 문제를 아이콘만으로 해결했다고 보고하지 않는다.

| 평가축 | 사전 평가 |
|---|---|
| 현재 흐름 적합성 | 전투→실제 획득 확인→마을 비교→다음 탐험에 연결 |
| 재미/명확한 목표 | 장비 발견·상위 요구 레벨 장비 식별이 소목표를 도울 가설. 고정 풀의 장기 반복 한계는 남음 |
| 조작/정보 직관성 | 약 두 행의 목록을 넓히고 장착 상태·비교 대상을 명시하는 효과를 검증 가능 |
| 확장 유지 가능성 | catalog 키별 아이콘과 읽기 전용 표시 모델 사용 시 도메인과 분리 가능 |
| 충돌/복잡성 | 새 등급·자동 소비를 제외하면 승인 경제와 저장 계약 보존 가능 |
| 비용 대비 효과 | 경제·전투를 다시 설계하지 않고 기존 불편과 시각 구분에 집중 |

사전 판정은 **조건부 적합**이다. 조건은 D1~D6 준수, 실제 Godot 캡처와 회귀 확인, 획득 표시가 미저장 보상을 확정 획득으로 오인시키지 않는 것이다. 총괄이 채택 범위와 파일 소유권을 확정한다.
