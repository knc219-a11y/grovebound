## 사전 기획 검토
실제 `game_designer` 하위 역할이 공통 문서·계약·관련 소스를 읽고 사전 검토를 회신했다. 제품 설계를 선택하는 변경이 아니므로 외부 게임 사례 조사는 생략했다. 현재 루프/구현 경계는 `../agents/GAME_DESIGNER.md`에 기록했다. AGENTS의 합성/진화 '다음 작업'과 입장 재화 '첫 파일럿'의 현행 우선순위 불일치를 발견해 운영 문장을 수정하고 과거 인계는 이력으로 보존했다.

| 평가 | 판정 근거 |
|---|---|
| 현재 흐름 적합성 | 실제 구현을 읽은 기획을 개발 전/후 연결 |
| 재미·명확한 목표 | 이번에는 운영 대상, 제품 재미는 미검증 |
| 조작·정보 직관성 | 검토/전달 형식으로 목표를 명시, 실제 UI 변경 없음 |
| 확장 유지 가능성 | 단일 역할 문서와 기존 공통 진입점 사용 |
| 충돌·복잡성 | 제품 쓰기 금지·총괄 결정·작은 버그 경량 검토 |
| 비용 대비 효과 | 중복 구현/승인 누락 방지 기대, 효과는 운영 가설 |

종합 **적합**. 총괄이 현 요청의 운영 개선 범위로 채택했다. 사용자 현재 요청이 역할 추가와 PR/main 반영 승인 근거다. 게임 설정 변경 승인은 포함하지 않는다. 대안인 모든 버그의 2~3개 게임 의무 조사는 비용이 커 채택하지 않고 작업 크기별 강도를 사용한다.

## 작은 모의 작업: 출전/대기 구분
기획이 기존 #11 구현으로 이미 제공됨을 확인했다. 총괄은 재구현을 배분하지 않고 QA 시나리오만 전달한다. 가상 결함이 있을 때의 파일 배분은 UI=`ui/companion_roster.gd`, QA=`tools/test_roster_layout.gd`와 독립 검토 장면, 총괄=`main.gd` 연결이다. 실제 파일 소유권 변경/제품 수정은 하지 않았다.

QA 전달 기준 M1=출전4/대기2/보관 문구 식별, M2=목록 선택→목적 슬롯 교체, M3=필터 없음·부분편성·중복종, M4=저장 실패 무변경과 탐험 HP/쿨다운 보존. 실제 제품 QA는 실행하지 않는다. 기존 361검사/48회귀는 #11 당시 결과이며 이번 통과로 세지 않는다.

가설: 구분된 상태 문구가 잘못된 편성을 줄인다. 향후 사람에게 특정 동료 찾기→상태 판별→지정 슬롯 교체를 수행하게 하고 완료 시간/오클릭/도움 요청을 관찰한다. 목표 수치는 미합의이며 임의 합격선은 두지 않는다.

## 검증 결과와 제한
- 실제 사전 역할 `game_designer`가 적합 회신 후 총괄이 문서를 작성했다. 크레딧 중단 뒤 기존 진행 중 역할이 유지되지 않아 독립 QA `qa_final`과 기획 사후 역할 `designer_final`을 새로 호출해 검토를 완료했다. 각 역할은 읽기 전용이며 작성자와 QA가 다르다.
- `qa_final`: D1~D5 절차/링크/권한/기존 원칙/무변경 독립 검토, blocking defect 없음. bundled Python으로 `tools/check_handoff.py` HANDOFF PASS, `git diff --check` 통과, 제품/씬/설정/에셋/저장 diff 없음 확인. 모의 M1~M4는 개발/QA로 전달할 시나리오이며 실제 제품 검사를 실행한 것으로 세지 않는다.
- `designer_final`: D1~D5 문서 수용 기준 충족, 사후 판정 적합, blocking defect 없음. 최초 의도·사전/사후 절차·권한·조사 강도·기준 ID 전달·새 Work 진입점 검토. 실제 UI 가독성/조작/플레이는 이번 변경 대상이 아니며 미검증이다.
- 총괄도 `tools/check_handoff.py`와 `git diff --check`를 실행하고 범위를 확인했다. 시스템 Python 별칭과 런타임 경로 조회 도구는 실패했으나 설치된 bundled Python 직접 실행은 성공했다. 셸 GitHub DNS 오류는 연결된 GitHub 앱으로 원격 읽기/브랜치/PR 작업을 대체한다.
- 이번 실제 Godot 플레이·새 렌더·모바일·사람 장기 체감은 미실행이다. 문서만의 검증은 플레이 경험의 검증이 아니다. 별도 worktree의 실제 병렬 제품 개발·수정 후 게임 QA는 이번에 실행하지 않았다. 새 Work에서의 자동 실행은 보장/검증되지 않았다. 원격 CI와 병합 결과는 PR/최종 보고에서 실제 ref와 함께 확인한다.
