# Grovebound · 야수의 계곡 — Prototype 0.2

모바일 가로 화면 몬스터 수집 RPG의 첫 Godot 플레이 프로토타입입니다.
**Godot 4.7 stable에서 임포트 및 핵심 규칙 검증을 완료했습니다.** GDScript / Compatibility 렌더러입니다.
팀과 CI의 기준 버전은 4.7 Standard입니다. 4.3 검증 기록은 이전 버전의 이력입니다.

## v0.2 변경

- 공격 시 반동/스쿼시, 이동 흔들림, 피격 강조, 쓰러짐 기울기, 적 처치 페이드.
- 피해/회복 숫자가 떠오른 뒤 사라지고 연결선은 짧게만 표시됩니다.
- 우두머리 2패턴: 원형 발구르기 → 직선 돌진을 번갈아 사용합니다.
- 발구르기 반경 130, 예고 1.15초. 돌진 폭 96, 길이 최대 340, 예고 1.25초.
- 돌진은 경로를 따라 판정하고 같은 공격으로 같은 대상을 중복 타격하지 않습니다.
- 미니맵: 빨간 점 일반 적, 주황 점 우두머리, 금색 원 포획 대상, 연두 점 동료, 흰 점 주인공.
- 동료 버튼 체력/스킬 준비 상태, 탐험 시간/처치 수, 보스 체력/패턴 안내.
- 터치를 UI 위에서 놓거나 창이 포커스를 잃어도 이동/소생 입력이 남지 않도록 보완.

정지 원화에 절차적인 변형을 추가한 단계입니다. 프레임별 손그림 애니메이션은 아직 아닙니다.
저장 파일 스키마를 변경하지 않아 v0.1과 같은 기기/사용자 계정에서 진행 데이터를 이어갑니다.

## GitHub로 업데이트하고 실행하기

저장소를 **최초 한 번만 clone**한 후, Windows에서는 `update-and-play.bat`를 실행하세요.

1. 변경된 게임 파일을 `git pull --ff-only`로 받습니다.
2. Godot 4.7이 없다면 공식 서버에서 `.tools/`에 한 번만 내려받습니다.
3. 에셋 임포트와 핵심 규칙 검증을 실행한 뒤 게임을 엽니다.

이미 최신 파일이면 **`play.bat`**로 바로 실행할 수 있습니다. GitHub Desktop으로 업데이트한 뒤 실행하는 경우도 이 파일을 사용하세요.
Godot 편집기에서 작업하려면 `project.godot`를 Godot 4.7 Standard로 가져온 뒤 F5를 누르세요.
로컬 수정이 있으면 자동 업데이트는 멈춥니다. 파일을 덮어쓰거나 강제 초기화하지 않습니다.
Windows 실행 파일 자동 설치와 런처는 작성했지만 Windows 실기기 실행 검증은 아직 하지 않았습니다.

GitHub Actions는 push/PR마다 Godot 4.7로 임포트와 핵심 규칙을 검사합니다.
저장소 주소가 연결되기 전에는 원격 Actions가 실행되지 않습니다.

엔진 공식 다운로드: https://godotengine.org/download/archive/4.7-stable/

## 처음 플레이

첫 동료 만나기 → 멧돼지/담비/여우 선택 → 접근해서 자동 공격 → 금색 포획 표시 가까이에서 F → 협동 전투 → 캠프 → 계곡으로 출발.

## 조작

| 행동 | PC | 터치 UI |
|---|---|---|
| 이동 | WASD / 방향키 | 왼쪽 가상 스틱 |
| 회복 | Q | 오른쪽 회복 버튼 |
| 야성 강화 | E | 오른쪽 야성 버튼 |
| 동료 고유 스킬 | 1 / 2 / 3 / 4 | 하단 동료 버튼 |
| 포획 | 가까이서 F | 포획 버튼 |
| 소생 | 가까이서 F를 3초 유지 | 소생 버튼을 3초 유지 |
| 동료 편성 | Tab | 우측 위 편성 |
| 일시정지 | Esc | 편성/귀환 창으로 일시정지 |

회복: 범위 내 살아 있는 파티원 중 체력 **비율**이 가장 낮은 대상. 주인공 포함.
강화: 범위 내 살아 있는 동료 중 공격력이 가장 높은 대상. 7초간 공격력 60% 증가.
소생: 이동/자동 공격/주인공 및 동료 수동 스킬 명령이 멈춥니다. 나머지 동료는 자동 전투를 계속합니다.
피격은 소생을 취소하지 않습니다. 중단하면 진행도가 초기화됩니다. 완료 시 체력 30%로 복귀합니다.

## 이번 버전에서 가능한 것

- 동료 없는 튜토리얼 시작, 첫 후보 3종 중 하나를 직접 포획
- 드루이드 + 동료 최대 4마리 출전, 최대 6마리 동행
- 야수 6종: 멧돼지/담비/여우/거북/사슴/늑대. 늑대는 적이면서 포획도 가능
- 역할별 자동 전투, 탱커 우선 유도/도발, 힐러 회복, 원거리 거리 유지, 주인공과 멀어지면 복귀
- 수동 동료 스킬, 자동 기본 공격, 적 공격 예고 범위
- 전투 밖에서 동행한 6마리끼리 순서 교체. 앞의 4마리가 출전
- 동행 자리가 있으면 포획 동료 합류, 초과 시 보관함 이동
- 개체별 고정 장점 특성 하나, 야생 레벨 유지
- 동행 6마리 동일 경험치, 재료 육성, 보관 동료 방생
- 우두머리 전투, 주인공 사망 시 실패, 포획/경험치/재료 유지
- 클리어 시 보너스 재료와 다음 지역 개방 기록
- 캠프에서 동행 선택, 데이터 자동 저장, 초기화 확인 창

캠프에서 각 동료의 이름을 차례로 눌러 순서를 바꿉니다. 출전/대기는 순서 기준입니다.
탐험 중 교체해도 체력과 쓰러진 상태는 유지됩니다. 재출발 시 동료와 주인공의 체력을 회복합니다.
일반 적 처치 시 포획 기회가 15% 확률로 발생합니다. 사냥터 앞 3곳의 반복 확정 포획은 제거했으며, 튜토리얼의 첫 동료만 보장합니다.
포획 기회가 발생한 뒤 가까이 가서 포획 버튼을 누르면 확정 성공합니다. 낮게 쉬는 자세와 작은 초록 잎 표식으로 표시합니다. 이 수치는 테스트용입니다.

## 그래픽 범위와 제한

- 생성한 카툰 원화를 실제 PNG 에셋으로 사용합니다. 반투명 여백을 가진 캐릭터 atlas를 셀별 분리했습니다.
- 정지 스프라이트 + 좌우 반전 + 이동 흔들림 + 스킬/피격 효과입니다.
- 방향별 걷기/공격 애니메이션, 음향, 완성된 타일맵은 아직 없습니다.
- 배경은 시안의 분위기를 따른 생성형 계곡 원화 1장을 맵 텍스처로 사용합니다. 재사용 가능한 타일맵은 후속 작업입니다.
- 하천과 나무는 현재 장식입니다. 이동은 탐험 영역의 직사각형 경계로 제한되며 장애물 경로 탐색은 후속 작업입니다.
- 전투 AI는 거리 기반입니다. 정교한 진형, 복잡한 길찾기, 적별 독립 힐러 AI는 아직 없습니다.
- 첫 맵 플레이 시간 목표는 5~10분이나 실제 사용자 플레이에 따른 밸런스 검증은 미완료입니다.
- 다음 스테이지는 개방 기록만 남기고, 콘텐츠는 포함하지 않습니다.
- 모바일 터치 입력 코드는 구현했지만 Android/iOS 실기기 테스트 및 설치 패키지는 미제공입니다.
- 탐험 중간 위치는 저장하지 않습니다. 재실행하면 캠프에서 시작하며 이미 획득한 보상은 유지됩니다.

## 저장

Godot `user://grovebound_v1.json`에 자동 저장합니다.
Windows 기본 위치: `%APPDATA%/Godot/app_userdata/Grovebound · 야수의 계곡/`
캠프의 **새 여정**을 누르고 확인하면 현재 프로토타입 데이터를 지웁니다.
이 패키지에는 개발자의 저장 데이터가 포함되지 않습니다.

## 구조

- `project.godot`: 가로 화면, 1440×810 기준, Compatibility 렌더러
- `main.tscn`: 실행 장면
- `main.gd`: 데이터, 전투, UI, 저장, 내장 검증
- `assets/`: PNG 에셋, Noto Sans KR 및 라이선스
- `DESIGN.md`: 합의한 방향과 이번 구현 범위
- `QA.md`: 검증 결과와 다음 테스트 항목
- `preview.png`: 이 프로젝트를 실제 Godot 렌더러로 캡처한 화면(포함된 경우)

## 개발자 검증

```bash
godot --headless --path . --editor --import --quit
godot --headless --path . -- --self-test
```

`--self-test`는 사용자 저장을 쓰지 않으며 주요 규칙과 튜토리얼 연결을 확인합니다.
`--screenshot`은 화면 검수용 연출을 설정하고 `preview.png`를 저장한 뒤 종료합니다.
스크린샷 모드 역시 사용자 데이터를 저장하지 않습니다.

## 이후 구현 우선순위

1. PC에서 튜토리얼~보스 완주, 각 스킬과 동료 4마리 버튼 부담 확인
2. Android 실기기 내보내기 / 멀티터치 / 화면 안전영역 / 성능 검증
3. 이동·공격·쓰러짐 애니메이션과 타일맵/장애물 길찾기
4. 고정 특성별 가치와 첫 맵 난이도/길이 조정
5. 저장 구조 마이그레이션과 데이터/AI/UI 스크립트 분리
6. 추가 지역과 고위 야수 → 마물조련사/네크로맨서 계열 확장

## 어두운 도트 콘셉트 적용

스테이지에 새 폐허 배경을 연결하고, 아군/일반적/우두머리 멧돼지를 고정팔레트 도트 스프라이트로 교체했습니다. HUD색과 멧돼지 초상도 함께 적용했습니다. 주인공과 다른 동물의 도트화는 후속 작업입니다. 배경의 벽/돌은 현재 장식이며 이동판정은 기존 방식입니다.

`animation/boar_pixel.gd`는 출력된 PNG만 사용합니다. 원화 재생성은 `experiments/pixel/README.md`를 참고하세요. 공격/달리기 전용프레임은 아직 없으며 빠른 이동 시 걷기 재생속도를 제한합니다.

실제 본편 전투검토 장면: `animation/pixel_gameplay_preview.tscn`. 이 장면은 세이브를 읽거나 쓰지 않습니다. 녹화: `docs/pixel-gameplay.gif`, `docs/pixel-gameplay.mp4`.

저장된 편성에 없는 동료ID가 남아 있으면 시작 시 복구합니다. 정상 보유동료와 성장/재료는 유지하며, 원본 저장은 같은 사용자 저장폴더에 `.backup-시간` 파일로 보관합니다. 저장파일을 수동으로 초기화할 필요는 없습니다.

## 동료 등급과 무작위 옵션
- 개체값 없음. 같은 종/레벨의 기본 능력치는 동일하며, 기존 고정 특성1개를 유지합니다.
- 일반/희귀/영웅: 옵션1/2/3개, 현재 임시 등급 확률75/22/3%(포획 기회15%와 별도).
- 옵션: 체력,공격력,피해 감소,이동 속도,동료 스킬 대기시간,기절 대상 추가 피해,회복량. 종/역할에 맞는 풀에서 중복 없이 뽑고, 특성과 같은 단순 능력치 옵션은 제외합니다. 수치도 개체별로 고정됩니다.
- 등급은 포획 전 표식1/2/3개와 녹색/파랑/보라,입자,짧은 효과음으로 구분합니다. 특성과 옵션은 획득 후 공개합니다.
- 전투 중 포획은 짧은 알림만 표시합니다. 전투 종료 후 왼쪽 위 ‘획득 동료 확인’,캠프의 ‘최근 동료’,보관함의 ‘상세·비교’를 사용합니다. 비교창은 현재 레벨 기준입니다.
- 기존 저장 동료는 일반 등급/옵션 없음으로 호환되며 능력치·특성·성장·편성을 보존합니다. 새 정보가 있는 저장은 재추첨하지 않습니다. 변경 전 원본 백업 정책은 유지됩니다.
- 등급 승급,옵션 재추첨,전설 등급,기존 동료에 옵션을 붙이는 기능은 이번 범위에 없습니다.
